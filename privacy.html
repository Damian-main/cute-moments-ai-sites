Privacy Policy

Last updated: October 20, 2026

Cute Moments AI is a personal project that prepares short animal videos and is being developed to support uploads to the owner's YouTube channel. This policy explains how information will be handled when YouTube integration is enabled.

Information accessed

With the account owner's permission, the project will use Google's OAuth authorization to obtain the access needed to upload videos to the owner's YouTube channel. This may include video files and the video title, description, and privacy setting supplied for an upload.

The project does not need the owner's Google password and does not intend to access Gmail, Google Drive, contacts, or unrelated Google account information.

How information is used

Authorized YouTube data is used only to carry out the owner's requested video uploads and report whether the upload succeeded. The project does not sell Google user data or use it for advertising.

Storage and service providers

The project uses GitHub to store its code and run scheduled workflows. When upload integration is configured, OAuth credentials will be stored in GitHub Actions secrets and used by the workflow for authorization. Credentials must not be committed to the source code or made public.

Generated video files may be stored as GitHub Actions artifacts. The current workflow is configured to retain these artifacts for seven days. Google, YouTube, and GitHub may process information according to their own privacy policies and terms.

Sharing and publication

The project does not sell or rent personal information. Videos uploaded to YouTube may become public, unlisted, or private according to the upload settings selected by the owner. YouTube handles published content under its own policies.

Security and retention

Reasonable steps will be taken to restrict access to credentials and project files. No online service can guarantee absolute security. The owner can remove stored credentials from GitHub and revoke the application's access through their Google Account. Deleting a local copy or workflow artifact does not automatically remove a video already uploaded to YouTube.

Children's privacy

Cute Moments AI is a video-production project, not a service designed to collect personal information from children.

Changes to this policy

This policy will be updated when the project's data practices materially change.
